## Overview

Project Alpha is a design system and component library built to accelerate UI development across multiple projects. It provides a consistent set of primitives, tokens, and components that make building interfaces faster and more reliable.

## Why?

Starting every project from scratch leads to inconsistency. Alpha solves this by providing a single source of truth for design decisions — colors, spacing, typography, and reusable components that follow the same patterns.

## Tech Stack

- **React 19** — Latest React with server component support
- **TypeScript** — Full type safety for all components
- **Storybook** — Interactive component documentation
- **Tailwind CSS** — Utility-first styling under the hood

## Key Features

- 40+ production-ready components
- Full dark mode support via CSS custom properties
- Accessible by default (ARIA labels, keyboard navigation)
- Tree-shakeable exports for optimal bundle size
- Comprehensive documentation with live examples

## What I Learned

Building a design system taught me the importance of thinking in systems — every component needs to work independently *and* compose together. The hardest part wasn't building individual components, but ensuring they all feel cohesive when used together.
